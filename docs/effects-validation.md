# 视觉趣味化一期验证

## 已实现

- `effects.py` 提供独立粒子引擎、矢量路径与按逻辑尺寸和显示缩放缓存的符号；同时存活上限 80，淘汰最老项。
- `pet.py` 的状态和事件配置表接入爱心、音符、怒气、眩晕星星、睡眠鼻涕泡、拎起感叹号、喂食碎屑、起跳和落地扬尘。
- 统一落地事件负责 0.25s / 0.4s 的压扁和过冲回弹；形变与既有动作相乘，按可见脚底对齐。
- 拖拽和下落时临时延长现有窗口，地面阴影保持固定的屏幕纵坐标。落地后窗口恢复；不创建特效窗口。
- 符号与气泡预留独立空间；动效开关立即清空粒子与符号，保留阴影和形变。从聊天窗口打开设置也会同步更新宠物。

## 需求中的两处取舍

- 第 2 节“关闭后静态身体”与第 3.6 节“保留阴影和形变”有差异；采用更具体的第 3.6 节。
- 40ms 更新间隔最高约 25fps，无法达到验收项的 30fps / 60fps 目标；实际改为 16ms 精确定时器。物理和粒子使用真实 dt，散步速度不随频率加快。

## 自动化与视觉验证

- 23 项单元测试通过。涵盖粒子位置、重力、阻尼、旋转、寿命、上限、固定冲击环、符号缓存与进退场、阴影固定地面、落地过冲、装饰开关、两批定时碎屑，以及缩放和聊天设置同步。
- 离屏检查六种情绪组合及拎起阴影；修复趴卧素材透明留白导致的脚底悬空。
- 1080p 逻辑画布、80 粒子 + 1 符号、缓存预热后 110 帧粗测：

| 显示缩放 | 平均绘制 ms | P95 ms |
| --- | ---: | ---: |
| 100% | 0.083 | 0.094 |
| 125% | 0.106 | 0.120 |
| 150% | 0.116 | 0.128 |
| 200% | 0.106 | 0.117 |

以上只测特效的离屏绘制，不包含窗口合成和整个桌面的帧率，不代表 Windows 实机结果。

## 尚需实机验证

Windows 11 的 125% / 150% 显示缩放、桌面输入穿透与窗口合成性能需要在 Windows 机器上验证。当前环境只有 macOS，不能据离屏绘制结果宣称 Windows 验收完成。
